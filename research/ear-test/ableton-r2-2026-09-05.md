### 01:28 — set saved

`~/Music/Ableton/flow-audio/endel-rebuild-r2 Project/endel-rebuild-r2.als` (Live's Save As always
creates a `<name> Project/` folder; that is why the path has one extra level).

**Why r1 was lost, and the tooling lesson.** Live's Save panel sanitises `/` out of the Save As
field, so writing a full path into that field produces a file literally called
`_Users_othersideinc_Music_Ableton_flow-audio_endel-rebuild-r1` — which is exactly what the r1
agent left behind, on the Desktop. Two further gotchas found this round:

- **Keyboard events posted from this agent's shell (`osascript ... keystroke`) never reach Live.**
  Mouse clicks posted through the computer-use MCP do reach it, and AX writes
  (`set value of text field ...` via System Events) do too. Anything needing typed text into a Live
  dialog must go through AX writes, not keystrokes.
- While a Save panel is up, Live's AX tree can go completely empty and MCP calls fail with
  "No data received". That is a modal-alert-behind-the-sheet condition, not a crash — the alert
  (here: "…flow-audio/" is an invalid file name) has its own window; dismissing it restores
  everything.

Desktop leftovers from the r1 mis-save were removed.

### Candidate A built — PAD-A dub stab (track 5)

Chain: Operator -> EQ Eight -> Echo -> Utility. Clip "A dub stab C3 E3 D4", 16 beats, 24 notes:
C3(48)+E3(52)+D4(62) struck on beat 2 (vel 55/55/95) and the "and" of 3 (vel 42/42/72) of every
bar, note length 0.25 beat — the amp envelope and the echo do all the shaping.

Raw parameter values written (Live units, as returned by set_device_parameter):

| device | param | value | intent |
|---|---|---|---|
| Operator | Algorithm | 10 | all-parallel; only Osc A has level |
| Operator | Osc-A Wave | 2 | square-ish, for a hollow stab |
| Operator | Ae Attack / Decay / Sustain / Release | 0.0 / 0.599 / 0.0 / 0.5 | instant attack, ~150 ms decay, no sustain |
| Operator | Osc-A Lev < Vel | 100 | so D4 really is the loud note |
| Operator | Filter Freq / Res | 1.0 / 0.0 | Operator's own filter out of the way |
| EQ Eight | 1 Filter Type A / 1 Frequency A | 1 / 0.41811 | low cut at 250 Hz |
| EQ Eight | 4 Filter Type A / 4 Frequency A | 6 / 0.71722 | high cut at 2.5 kHz |
| Echo | Feedback | 0.675 | 67.5 % |
| Echo | HP Freq / LP Freq | 0.3333 / 0.7671 | 200 Hz / 4 kHz |
| Echo | Dry Wet | 0.45 | |
| Echo | L/R 16th, L/R Sync Mode | 3, 2 (defaults, untouched) | the 3/16 the r1 set already used |
| Utility | Output | -0.343 | -12 dB, provisional — calibrated against the measurement below |

**Unit mappings derived this round** (Live's MCP API returns raw floats with no display string, so
these had to be reverse-engineered; they are the reason the numbers above are not round):

- **EQ Eight frequency**: `f = 10 Hz x 2205^x`, i.e. `x = ln(f/10)/7.6986`. Confirmed exactly — the
  eight factory default frequencies come back as 30, 40, 200, 1000, 2000, 5000, 10000 and 18060 Hz
  under this formula, which is too clean to be a coincidence.
- **Echo HP/LP frequency**: `f = 20 Hz x 1000^x`, `x = ln(f/20)/6.9078`. Anchored on the r1 set,
  where HP 0.333 displayed as 200 Hz and LP 0.799 as 5.00 kHz.
- **Utility Output (gain)**: parameter range -1..+1 maps linearly to -35..+35 dB, so `x = dB/35`.
- **Auto Filter frequency**: `f = 30 Hz x 560^x` (one-point calibration off r1's 0.705 = 2.60 kHz)
  — the weakest of the four, treat as +/- 15 %.
- **Operator envelope times**: assumed `T = 0.1 ms x 200000^x`. NOT verified; the Operator decay
  values below should be read as "short" / "long", not as milliseconds.

### Candidates B, C, D built; export route established

- **B (track 6)** Wavetable -> Auto Filter -> Echo -> Utility -> Auto Pan-Tremolo. Clip
  "B open fifth C3 G3 D4": C3(48) G3(55) D4(62) held for the whole 16 beats, vel 70/66/58 — an open
  fifth plus the ninth, no third.
- **C (track 7)** Operator -> Auto Filter -> Echo -> Utility. Clip "C tick D4 5-of-16": one note,
  D4(62), 20 hits, five per bar on sixteenths 1, 4, 6, 9 and 12 (beats 0, 0.75, 1.25, 2.0, 2.75),
  velocities 30-48 and varied bar to bar so it does not read as a loop.
- **D (track 8)** Analog -> Auto Filter -> Echo -> Saturator -> Utility. Clip
  "D resonant chord C3 E3 G3 D4": four notes held for the whole 16 beats, vel 72/60/64/78.

**Two deliberate deviations from the brief, both forced by the MCP's API surface:**

1. **B's level swell is an Auto Pan-Tremolo, not a clip envelope.** ableton-mcp exposes notes and
   device parameters but no clip-envelope API, so "-12 dB to 0 dB over 4 bars in the clip envelope"
   is not writable. It is done instead with Auto Pan-Tremolo in Tremolo mode, Amount 0.35, synced to
   64/16 = 4 bars — a slow sine swell of roughly 12 dB, which is the same gesture. It is NOT the fast
   tremolo of round 1 (which ran at Amount 0.92 on a short sync division); the device is the same, the
   rate and depth are not. It also sits after Echo in the chain, because devices can only be appended,
   so it breathes the echo tails as well as the source.
2. **D's cutoff sweep is 16 bars only approximately.** Auto Filter's synced LFO caps at 64/16 = 4
   bars, so D's LFO is left free-running with LFO Freq 0.134, aimed at ~0.03 Hz = 32 s = 16 bars.
   The real period is unknown until measured; the measurement pass reports it.

Also: this MCP has **no track-mute tool**. Solo/mute for the exports is done with the `Mute` parameter
inside each track's Utility device, and the round-1 PAD track (track 2) is silenced the same way.

**Export route** (same as r1): clips duplicated into the Arrangement 4x at beats 0/16/32/48, then
File > Export Audio/Video with Rendered Track = Main, WAV, 24-bit, 44100, Normalize Off, Render Start
1.1.1, Render Length 16.0.0. Two more tooling notes:

- Live's Render Start / Render Length number boxes **ignore AX value writes** but do respond to
  `perform action "AXIncrement"` / `"AXDecrement"`, one bar per call. That is how the range was set.
- The export Save panel has the same Where-folder problem as Save As, so everything is exported into
  whatever folder Live last used and then moved into place with `mv`.
