# Palettes for the ear test

A palette = one sound world that stays consistent for a whole session. Daniel's thesis: rotate
palettes without breaking the flow. Written 2026-09-02 from Daniel's own description, translated
into production terms; awaiting his confirmation of the translation.

## Palette A — "Deeper Focus" lane (quality bar)
Hypnotic monotone minimal techno in the Plastikman / Endel Deeper Focus character. Constant pulse,
deep sub, one filtered chord, no melody, no vocals, no build-ups, no drops. Tempo: reference measured
114.8 BPM (Daniel's SoundCloud set, agent pass; a quick 2-min pass said 112); Endel recording ~120 but weak evidence.

## Palette B — "dub / subtle rave" lane (Daniel, 2026-09-02, own words paraphrased)
- Deep sub bass locked to the kick, sine-like, felt more than heard.
- A hypnotic 2–3 note motif through a tempo-synced dub delay; the echoes make the rhythm.
- Monotone: one key, no chord changes; only filter/echo movement on the motif.
- Subtle rave: old-school rave chord stabs, low-passed, pushed far back — a hint, not party music.
- Occasional distant, muted, reverb-soaked trumpet/horn-like pad.
- NEVER: psytrance rolling bass, acid squeals, fast arpeggios, risers, drops, breaks, vocals.
- Tempo window 112–120 BPM ("definitely not too fast"). Note: the first ElevenLabs Palette B batch (see generation-log-2026-09-02.md) used a plainer dub-techno brief written before this description existed; the next batch must follow this section.

## Palette C — half-time / dubstep-ish (proposed earlier, not yet confirmed)
Wobbly bass at half-time, no drops, stays calm. Daniel to confirm or drop.
